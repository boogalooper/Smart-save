# Smart save

**Smart save** — JSX-скрипт для Adobe Photoshop, предназначенный для автоматизированного сохранения документов с формированием имени файла и структуры каталогов по настраиваемым правилам.

Скрипт может использоваться как вручную, так и в составе Photoshop Actions. Формат и параметры сохранения выбираются в стандартном диалоге Photoshop, поэтому Smart save не ограничивает пользователя заранее заданным набором форматов.

## Возможности

- сохранение в каталог исходного документа или в выбранный каталог;
- автоматическое создание подкаталогов;
- составное формирование имени файла и имени подкаталога;
- использование имени документа, активного слоя, расширения, каталогов, метаданных, размеров, даты и времени;
- добавление произвольного текста;
- поиск и замена фрагментов сформированной строки;
- последовательная нумерация файлов;
- изменение регистра, фильтрация символов и транслитерация;
- автоматическое добавление числового суффикса при совпадении имен;
- пользовательские пресеты правил именования;
- сохранение через стандартный диалог Photoshop с поддержкой параметров выбранного формата;
- сохранение и повторное использование параметров формата в Photoshop Actions;
- тихое выполнение из Action без повторного открытия диалога сохранения.

## Установка

Скрипт можно запускать непосредственно через **File → Scripts → Browse...** и выбрать файл `Smart save.jsx`.

Для постоянного использования файл можно поместить в каталог скриптов Photoshop (`Presets/Scripts`) и перезапустить Photoshop. После этого Smart save появится в меню **File → Scripts**.

## Основное использование

1. Откройте документ в Photoshop.
2. Запустите **Smart save**.
3. Выберите каталог назначения:
   - **save in the same directory** — каталог текущего документа;
   - **save to new directory** — произвольный каталог, выбранный через **Browse**.
4. При необходимости включите создание подкаталога и настройте его имя на вкладке **Subfolder name**.
5. Настройте имя сохраняемого файла на вкладке **File name**.
6. Проверьте результат в панели **Preview**.
7. При необходимости измените режим обработки совпадающих имен.
8. Нажмите **Save file**.
9. В стандартном диалоге Photoshop выберите формат и его параметры.

Если требуемого каталога или сформированных подкаталогов не существует, Smart save создаст их автоматически.

После первого успешного сохранения выбранный Photoshop формат отображается в главном окне рядом с каталогом назначения.

## Конструктор имени

Имя файла и имя подкаталога формируются как последовательность элементов. Кнопки **+** и **−** добавляют и удаляют элементы. Элементы обрабатываются сверху вниз, а их результаты объединяются в одну строку.

Для каждой вкладки можно использовать до десяти элементов.

### Document

Добавляет данные текущего документа:

- **Name** — исходное имя файла без расширения;
- **Layer name** — имя активного слоя;
- **Extension** — расширение выбранного формата сохранения;
- **Folder** — имя каталога документа;
- **Parent of folder** — имя каталога уровнем выше;
- **Author** — поле Author из метаданных документа;
- **Title** — поле Title из метаданных документа;
- **Camera model** — модель камеры из EXIF, если она доступна.

Для строковых значений можно выбрать регистр и фильтр символов:

- без изменения;
- только буквы;
- только цифры;
- только латиница;
- только кириллица;
- транслитерация CYR → LAT;
- транслитерация LAT → CYR.

### Dimensions

Добавляет размеры документа или разрешение.

Доступны варианты:

- альбомная запись `WxH`;
- портретная запись `WxH`;
- фактическое `WxH`;
- только ширина;
- только высота;
- разрешение.

Размеры могут быть представлены в `cm`, `mm`, `in` или `px`. Для физических единиц доступно округление до целого, десятых или сотых.

### Date, time

Добавляет дату или время на основе:

- даты создания файла;
- даты изменения файла;
- текущей даты и времени;
- вчерашней даты;
- завтрашней даты.

Доступны отдельные компоненты и комбинированные форматы, например `YYYY-MM-DD`, `DD-MM-YYYY`, `HH-MM-SS`, `YYYY`, `MM`, `DD`, `HH`, `MM`, `SS`.

### Text

Добавляет произвольный текст в текущую позицию имени.

Например, комбинация:

```text
Document: Name
Text: _web
Dimensions: WxH / px
```

может сформировать имя:

```text
DSC01234_web_6000x4000
```

### Substitution

Изменяет уже сформированную часть строки. Можно указать искомый текст и выполнить одно из действий:

- заменить найденный текст;
- добавить текст перед найденным фрагментом;
- добавить текст после найденного фрагмента.

Поиск выполняется без учета регистра.

### Sequence

Доступен при формировании **имени файла** и добавляет числовой счетчик.

Настраиваются:

- начальное значение;
- количество знаков — от 1 до 5;
- режим увеличения счетчика.

Режим **Every save** увеличивает значение при каждом сохранении. Режим **Every document** увеличивает его при переходе к другому документу.

Состояние счетчика хранится отдельно для каждого записанного шага Action.

### Subfolder

Доступен при формировании **имени подкаталога**. Позволяет добавить дополнительный уровень каталога внутри формируемого пути.

## Предпросмотр и совпадающие имена

Панель **Preview** показывает исходное имя документа и результат текущих правил именования.

Параметр **replace file in the destination directory if the names match** определяет поведение при существующем файле с таким же именем.

Если замена отключена, Smart save автоматически подбирает свободное имя:

```text
image.jpg
image_1.jpg
image_2.jpg
...
```

## Пресеты

Пресеты предназначены для быстрого переключения между наборами правил именования.

В пресете сохраняются:

- правила имени подкаталога;
- состояние создания подкаталога;
- правила имени файла;
- состояние переименования файла;
- режим обработки совпадающих имен.

Каталог назначения и параметры формата Photoshop в пресет не входят.

Кнопки панели пресетов:

- **Save** — обновить выбранный пресет;
- **Add new** — создать новый пресет;
- **Delete** — удалить выбранный пресет;
- **↺** — восстановить сохраненные значения выбранного пресета.

Пресет **default** является базовым и не удаляется.

## Формат сохранения

Smart save не содержит собственного списка форматов и не задает параметры JPEG, TIFF, PSD и других типов файлов.

При обычном запуске после нажатия **Save file** открывается стандартный диалог сохранения Photoshop. В нем можно выбрать любой доступный формат и поддерживаемые Photoshop параметры этого формата.

Скрипт сохраняет выбранные параметры и использует соответствующее расширение при дальнейшем формировании имени файла.

В современных версиях Photoshop приоритетно используется режим **Save a Copy**. Если он недоступен и интерактивная команда завершается ошибкой, скрипт повторяет сохранение через совместимый режим **Save As**.

## Использование в Photoshop Actions

Smart save рассчитан на запись в Action и последующее автоматическое выполнение.

### Запись Action

1. Включите запись Action.
2. Запустите Smart save.
3. Настройте каталог и правила именования.
4. Нажмите **Save file**.
5. Выберите формат и параметры в стандартном окне Photoshop.
6. Завершите запись Action.

В шаге Smart save сохраняются правила формирования пути и имени, а также параметры выбранного формата Photoshop. В раскрытом шаге Action отдельно отображается поле **SaveFormat**, позволяющее быстро увидеть сохраненный формат.

### Тихое воспроизведение

При обычном запуске записанного Action Smart save работает без открытия собственного интерфейса и без диалога формата.

Для каждого документа скрипт:

1. формирует актуальный путь и имя;
2. создает отсутствующие каталоги;
3. применяет сохраненные параметры формата;
4. выполняет сохранение;
5. обновляет счетчик после успешного сохранения.

Путь и имя из первоначального диалога Photoshop не используются напрямую: при каждом запуске они заменяются результатом текущих правил Smart save.

### Изменение записанного шага

Откройте шаг **Smart save** в палитре Actions двойным щелчком.

В режиме редактирования доступны две отдельные команды:

**Save settings**  
Сохраняет изменения каталога, правил имени, подкаталога и других параметров Smart save. Сам документ не сохраняется, а текущие параметры формата Photoshop остаются без изменений.

**Save again…**  
Выполняет новое интерактивное сохранение. Используйте эту кнопку, если требуется изменить формат или его параметры. После сохранения новый набор параметров заменяет сохраненный ранее.

Текущий формат отображается в окне Smart save в поле **Format**.

## Особенности работы с несохраненными документами

Режим **save in the same directory** требует, чтобы текущий документ уже имел путь на диске.

Для нового несохраненного документа необходимо выбрать **save to new directory** и указать каталог вручную.

## Локализация

Интерфейс поддерживает русский и английский языки и использует текущую локаль Photoshop.

## Совместимость настроек

Текущая версия использует отдельный идентификатор настроек и не пересекается с настройками более ранних вариантов Smart save.

Ранее записанные шаги Action, использующие старую структуру параметров сохранения, не предназначены для прямого использования с этой версией. Для надежной работы рекомендуется записать шаг Smart save заново.
